### C1: coding — merge intervals

```text
Implement a Python function `merge_intervals(intervals)`.
- `intervals` is a list of intervals; each interval is a list of two integers [start, end] with start <= end.
- Malformed input must raise ValueError: an interval that is not a list of exactly two integers, a non-integer value (booleans are NOT integers), or start > end.
- Return a new list of merged intervals sorted by start, without mutating the input.
- Intervals that overlap OR share an endpoint merge; intervals that are merely adjacent integers do not.
Examples: [[5,7],[1,3],[3,4],[9,9]] -> [[1,4],[5,7],[9,9]]; [] -> []; [[1,2],[3,4]] -> [[1,2],[3,4]].
Reply with exactly one fenced ```python code block containing the complete function and nothing else.
```
